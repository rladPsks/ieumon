# 이음ON

통신·카드의 집계 변화 신호를 해석하고 공식 복지정책 대응으로 연결하는 **Human-in-the-loop 사회적 고립 예방 분석 Agent**의 공개 데모입니다.

## 데모가 보여주는 것

- 통신 30,466개 `250m 생활권 × 월` 관측에서 발견한 GMM 활동변화 유형 5개
- 도시·월 효과를 보정한 유형별 핵심 지표 프로파일
- 카드 42개 주간 특징행과 10개 도시×월 소비 맥락
- 높은 정책 검토 우선순위가 2개월 이상 지속된 생활권 429개
- 비식별 대표 사례 3건의 공식 정책 후보와 RAG 근거
- 공개 집계 결과를 자연어로 종합하는 로컬 Qwen 분석 Agent

현재 승인된 결과는 `정기·관찰·높음·최우선` 4단계 **정책 검토 우선순위**입니다. GMM 군집번호는 위험등급이 아니며, 개인의 사회적 고립이나 복지 자격을 판정하지 않습니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

모든 분석 탭은 즉시 동작하며, 첫 자연어 질문 시 경량 Qwen 모델을 배포 서버에 내려받아 초기화합니다.

## 로컬 생성 AI

API 키 없이 `Qwen/Qwen2.5-0.5B-Instruct`를 직접 실행합니다. 다른 호환 모델을 사용하려면 Streamlit Secrets 또는 환경변수로 모델 ID만 변경할 수 있습니다.

```toml
QWEN_MODEL_ID = "Qwen/Qwen2.5-0.5B-Instruct"
```

모델 입력에는 이 저장소의 공개·집계 분석 결과와 공식 정책 후보만 포함되며 원자료, 격자 식별자, 좌표, 개인정보는 포함하지 않습니다. 메모리나 모델 다운로드가 제한된 환경에서는 검증된 규칙 응답으로 자동 대체됩니다.

## 공개 데모 원칙

- 대회 제공 통신·카드 원본을 포함하지 않습니다.
- 격자 식별자, 좌표, 개인 식별값을 공개하지 않습니다.
- 카드 결과는 도시×월 공유 맥락으로만 사용합니다.
- 정책 추천은 담당자 검토 후보이며 자격과 운영 여부를 자동 확정하지 않습니다.
- 생성형 AI 사용 여부와 사용 범위를 화면에 고지합니다.
